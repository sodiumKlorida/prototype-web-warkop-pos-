# ☕ Warkop POS Prototype

Sistem Kasir dan Admin Panel berbasis web sederhana yang dirancang khusus untuk Warung Kopi (Warkop). Prototype ini menampilkan antarmuka yang bersih, responsif, dan mudah digunakan.

## 🌐 Live Demo
Coba langsung prototype-nya di sini:
**[Demo Website](https://prototype-web-warkop-pos.vercel.app/)**

## ✨ Fitur Utama (UI/UX)
1. **Manajemen Menu (Kelola Menu):**
   - Form input untuk menambah menu baru beserta kategori (makanan, minuman, cemilan) dan harga.
   - Tampilan daftar menu dalam bentuk *card* yang responsif.
2. **Melayani Pesanan (Sistem Kasir):**
   - Antarmuka *Point of Sale* (POS) interaktif untuk memproses pesanan pelanggan.
   - Tombol filter kategori menu untuk pencarian cepat.
   - Sistem keranjang (cart) dengan kemampuan mengatur kuantitas (+/-) dan rincian total pembayaran.
3. **Laporan Penjualan:**
   - *Summary cards* untuk ringkasan pendapatan hari ini, total pesanan, dan menu terlaris.
   - Tabel riwayat transaksi yang rapi, dilengkapi dengan fitur pencarian dan paginasi.
